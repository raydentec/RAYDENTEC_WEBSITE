IMPLEMENTATION SPEC

RAYDENTEC site — behavior & layout

Fonts (Google): Russo One 400 · Sora 500/600/700
Chakra Petch 500/600/700 · IBM Plex Mono 400/500

Breakpoints & frames

  • Desktop ≥ 1280px (comps 1440×810). Tablet 768–1279px (comps 1024×778). Mobile < 768px (comps 390×844).
  • App shell is a fixed viewport (100dvh); only the content column scrolls. Top accent bar 6px #CC181E. Footer fixed: 46px, 1px red top rule, Chakra Petch 600 12px grey.
  • Background: linear-gradient(180deg, rgb(204 24 30 / .25), transparent 48%), #000 — fixed, never scrolls. The blue bottom gradient is removed; keep --c-blue: #0039F0 as a reserved token.
  • Video background (as on raydentec.com): <video class=bg-video autoplay muted loop playsinline preload=auto aria-hidden=true> fixed, inset 0, object-fit: cover; mix-blend-mode: screen; opacity: .9; pointer-events: none; z-index: 0 — above the page gradient, below all UI. A script sets src to lightning-desktop.mp4 at (min-width: 1024px), else lightning-mobile.mp4, swapping on media-query change. prefers-reduced-motion: reduce → no video (display: none, never load). Use a poster frame.
  • Content column: 994px desktop / 776px tablet / 346px mobile. Outer gutters 52 / 28 / 22px. Container gap 16px (22px mobile).

Top navigation

  • Four routes: Start, Games, Projects, Community (hash or path routes; each loads its container list into the content column).
  • Centered on the viewport, Sora 600 36px (32 tablet), ls −0.04em, 36px gap. Active = white + aria-current="page"; others 50% white; hover → 80% white.
  • Mobile: nav moves to a bottom bar button (see Mobile).

Desktop sidebar

  • Expanded (320px wide, left 52px): logo tile 170, RAYDEN, tagline + @RAYDENTEC, 5 social icon links, bio, “Join me on this journey:”, Watch my videos (primary), Connect on socials (secondary). Collapse button (← 56×56) sits to its right, aligned with the nav row.
  • Auto-collapse when content scrollTop > 80px (only if the user did not pin it open via Expand in this scroll session). Re-expands automatically only at scrollTop = 0.
  • Collapsed rail (56px): logo tile 56, EXPAND button (56×300, vertical label, → icon), and at the bottom “Join me:” + VIDEOS (red fill) and SOCIALS (outline) 56×56 buttons.
  • Expanded: content column sits right of the sidebar (x = 416). Collapsed: content column re-centers on the viewport. Animate left/width 320ms cubic-bezier(.2,.8,.2,1); sidebar content fades 160ms.

Tablet sidebar

  • Default is the collapsed rail. EXPAND opens a 400px black panel OVER the content (does not push it); content gets a 50% black dimmer.
  • Closes on: ← button, dimmer click, Esc, or any scroll of the content. Focus moves into the panel on open and back to EXPAND on close.

Containers & scroll snapping

  • Content column uses scroll-snap-type: y mandatory; each container scroll-snap-align: start with scroll-margin-top = 0. Scroll top aligns with the nav bottom + 12px.
  • The snapped container is ACTIVE: 2px red border, solid red highlight column (45px desktop, 40 tablet) with its number in black. Others are INACTIVE: 1.5px border at 50% red, a notch tab carrying the number in 60% red, content at 42% opacity. Transition 240ms.
  • Number placement is unified on every page: highlight column / notch tab on the LEFT, number at the TOP. Layout varies by page: Community = image left, text right. Games = key art left (same inset as Community), text right. Projects = text left, image right. Start = same container (red highlight column / notch tab, same width) but WITHOUT numbers: intro (530px, banner image on top, text below) + explore grid.
  • Determine active via IntersectionObserver (threshold ≥ 0.6) or scrollend; keyboard focus inside an inactive container also makes it active. Numbers restart at 1 per page.
  • Mobile: number sits in a top tab — active = full-width red bar, inactive = 86px notch tab.

Scroll indicator / Back to top

  • At scrollTop = 0: “SCROLL ↓” (318×56). Click scrolls to the next container.
  • After scrolling: becomes “BACK TO TOP ↑”; click smooth-scrolls to 0 (respect prefers-reduced-motion → instant).
  • After 1.2s without scroll the button collapses to its 56×56 arrow-only form (width animates from the right edge, 200ms); any scroll re-expands it.
  • Style: 2px white border, rgb(255 255 255 / .5) fill + 6px backdrop blur, Chakra Petch 600 24px white. Same 50% white fill on EXPAND, collapse (←) and arrow-only buttons. Right-aligned to the content column, 16px above the footer rule (mobile: 12px above the menu bar).
  • A 6px scroll track sits at the far right; the red thumb maps the content scroll.

Mobile

  • Top of page: profile block is the first item in the scroll flow (logo 140, name, tagline, socials, bio, CTAs). Bottom fixed: SCROLL button (full width) above the page menu bar.
  • Once the profile block scrolls out (its bottom passes the header line), a fixed 121px header appears: logo 72, RAYDEN, tagline, @RAYDENTEC and a SOCIALS 54×54 button (opens the social links sheet/anchor). Content scrolls beneath and is masked at the header bottom (clip, not overlap).
  • Bottom menu bar (346×54, black, 2px red border): current page name + ☰. Tap opens a panel growing up from the bar with the 4 pages (56px rows, active row: 6px red left bar + red tint); bar icon becomes ×. Content dims 50%. Close on select, ×, dimmer or Esc.
  • Back-to-top on mobile is the collapsed 54×54 arrow at right, above the menu bar.

Accessibility

  • Real <a> / <button> elements; icon-only controls carry aria-label; sidebar toggles use aria-expanded + aria-controls.
  • Red (#CC181E) on black is 3.9:1 — use it only for text ≥ 18px semibold (buttons, handle). Grey #808080 on black passes 5.3:1. Inactive (dimmed) cards remain readable on focus/hover (opacity → 1).
  • Visible focus ring: 2px white outline, 3px offset. Touch targets ≥ 44px. prefers-reduced-motion: disable snapping smooth-scroll and collapse animations.
